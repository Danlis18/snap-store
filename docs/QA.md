# SNAP — перевірка версії 1

Оновлено: 20.09.2026. Середовище: Node.js 24, локальні тимчасові бази, тестовий SMTP-сервер і локальні відповіді Resend, які не відправляють повідомлення назовні.

## Оновлення 20.09.2026

- `npm run build` і всі 33 тести `node --test tests/*.test.js` пройдено.
- Додано перевірки HTTPS-відправлення Resend, відмов провайдера, сумісності SMTP, точного admin allowlist, двомовного листа та 60-секундного обмеження повторного коду.
- UI-сценарії проходять також без `crypto.randomUUID`: використовується криптографічний `getRandomValues`. Сторінка оформлення більше не падає у HTTP preview.
- У браузері Chrome перевірено основні екрани в контейнерах 320, 390, 430, 768 і 1280 px: шапку, каталог, вибір розміру, обране, кошик, вхід, оформлення й доставку; світлу та темну теми. Контейнери мають звичайну смугу прокручування браузера, тому доступна ширина вмісту може бути на 15 px меншою.
- PNG логотипа, знака й перевізників використовуються у вихідному вигляді. Перевірено завантаження, вирівнювання лічильників і сітку 2/4 картки.
- У Railway підтверджено правильний репозиторій `Danlis18/snap-store`, гілку `main`, одну репліку і Volume `/data`. Поштових змінних у сервісі не було. Підключення реального відправника та доставка кодів покупцям ще потребують завершення; успіх зовнішньої доставки не заявляється.

Це браузерна перевірка адаптивної верстки, не фізичні iPhone/Android і не замір швидкодії на них. Початковий звіт нижче збережено із зазначеними межами.

## Відкриті перевірки перед рекламою

Початкова браузерна перевірка 19.09 була перервана. Повторна перевірка основних сторінок 20.09 успішно виконана, як описано вище. WebGL, усі анімації та продуктивність на фізичних телефонах залишаються окремим прийманням.

| Перевірка власником / на staging | Очікування |
| --- | --- |
| iPhone Safari: 375, 390, 430 px; Android Chrome: 360, 412 px | Немає горизонтального прокручування, кнопки зручні, 2 картки в ряд, клавіатура не закриває дію |
| Десктоп 1440+ px | 4 картки в ряд, фільтри збоку, читабельні тексти |
| Навігація клавіатурою | Фокус видимий, dialog утримує фокус, Escape закриває панель, можна завершити оформлення |
| Тема, мова, перезавантаження | Обрані налаштування зберігаються; ключові сторінки перекладені |
| 3D Studio | WebGL запускається, обертання дотиком/кнопками, пауза, reduced-motion, відновлення після зміни вкладки |
| Відсутній WebGL | Пояснення замість порожнього блока; товари доступні |
| Повільний інтернет і мобільний CPU | Зображення завантажуються, кнопки блокуються на час запиту, немає подвійного замовлення |
| Реальна пошта Resend / SMTP | Код доходить до Gmail/Outlook, налаштовані домен відправника та автентифікація у провайдера |
| Перша реальна покупка | Два листи, адреса, післяплата, ТТН, статуси, бонуси, відгук, контрольне повернення |
| Фото та ціни | Всі демо-матеріали реальних товарів замінені, розміри відповідають вимірам |
| Аналітика | Немає сторонніх тегів до згоди; відмова та відкликання працюють; події видно у тестових кабінетах провайдерів |
| Зовнішній AI | Модель підтримує JSON; помилка провайдера позначається переходом на правила; бюджет дотримано |

Docker у поточному середовищі не доступний, тому складання Docker-образу не виконувалося. Перевірений Node production-процес використовує ту саму команду запуску застосунку. DNS, зовнішня доставка листів, рекламні кабінети, LLM-провайдер, API перевізників та навантажувальний тест не перевірені.

## Межі

Навантажувальні показники, SLA та результати незалежного аудиту не вимірювалися. Приймання має спиратися на пройдені перевірки та виконання відкритого списку вище.

WebMCP перевірено через тестовий реєстр API у DOM-середовищі. Реальна інтеграція з браузером, який підтримує цей запропонований стандарт, залишилася неперевіреною; звичайний магазин від неї не залежить.
