# Матеріали SNAP

- `public/snap-logo.png` — логотип із наданого користувачем зображення. Файл не перемальовано; оформлення у світлій темі виконується CSS-фільтром.
- `public/favicon.svg` — векторний знак для цього сайту.
- `public/assets/puffer.webp`, `tshirt.webp`, `hoodie.webp`, `sneakers.webp`, `cargo.webp`, `bag.webp` — згенеровані для макета предметні зображення без логотипів. Не фотографії оригінальних брендових товарів і не підтверджений асортимент магазину. Вони мають статус демонстраційних.
- Скриншот ANSWEAR використано як референс навігації та каталогу; чужі товарні фотографії й код у комплект не включені.
- Іконки: Lucide. Шрифт: Manrope через локально встановлений `@fontsource-variable/manrope`; завантаження з Google Fonts немає.
- React, Express, Three.js та інші залежності наведені в package.json, зафіксовані у package-lock.json. Їхні власні ліцензії розповсюджуються разом із відповідними npm-пакетами.

Перед початком продажів замініть всі шість повторюваних демо-зображень у реальних картках власними фотографіями товарів. За потреби змініть головний банер у налаштуваннях магазину.
