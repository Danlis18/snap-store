# SEO для SNAP

Дата підготовки: 19.09.2026. Основна мова пошукових сторінок — українська. Перемикач EN є зручністю інтерфейсу; окремих індексованих `/en/` адрес і hreflang у першій версії немає.

## Що реалізовано

Стабільні адреси категорій, брендів і товарів. Сервер повертає title, description, canonical та початковий текст до виконання JavaScript. Реальні картки отримують Product/Offer у JSON-LD: гривні, актуальна ціна, наявність, фото. Схема не приписує репліці виробника оригінального бренду й не створює вигадані рейтинги. Метадані оновлюються також при переходах усередині застосунку.

Sitemap містить активні реальні товари та бренди з такими товарами. Демо-картки, фільтри з query-параметрами, кабінет, checkout і адмінка закриті від індексації. До відкриття продажів і окремого ввімкнення індексації robots.txt забороняє обхід всього сайту. Canonical бере домен із `APP_URL`.

Підхід до URL спирається на [офіційні рекомендації Google для ecommerce](https://developers.google.com/search/docs/specialty/ecommerce/designing-a-url-structure-for-ecommerce-sites). Це технічна підготовка; вона не гарантує позиції чи схвалення конкретних товарів рекламною платформою.

## Початкова семантична карта — гіпотези

Це редакційні групи на основі брифу, не виміряний рейтинг популярності.

| Сторінка | Основна тема | Приклади запитів для перевірки |
| --- | --- | --- |
| `/` | Назва магазину | SNAP магазин, SNAP Store Україна |
| `/catalog/clothing` | Чоловічий одяг | чоловічий одяг репліки, люксові репліки одягу Україна |
| `/catalog/shoes` | Взуття | чоловічі кросівки репліки, репліки взуття купити |
| `/catalog/accessories` | Аксесуари | чоловічі аксесуари репліки, сумки репліки Україна |
| `/brands/Prada` | Бренд із точним позиціонуванням | Prada репліка чоловічий одяг, Prada репліки Україна |
| Картка конкретного товару | Модель, тип, варіант | [бренд] [назва моделі] репліка [тип товару] |

Публічний пошук за українськими фразами у цій сесії дав переважно нерелевантні результати. Достовірної статистики частотності, CPC чи конкурентності немає. Google Keyword Planner та Search Console не підключені. Тому тверджень «це топ-запити Google» або прогнозу трафіку немає.

## Що робити після наповнення

1. Замінити демонстраційні назви, описи, фото та заміри реальними. Указувати «репліка» там, де це відповідає товару; не маскувати під оригінал.
2. Для товарів написати окремі корисні описи: посадка, точні заміри, комплектація, доступні варіанти, догляд. Не копіювати тексти магазинів-референсів.
3. На власному домені підключити Search Console, перевірити rendered HTML вибраної картки та Product/Offer, відправити sitemap після відкриття продажів.
4. Перевірити групи у Keyword Planner для України та української мови. Визначити пріоритети за реальними даними. Не створювати сотні однакових фільтр-сторінок під варіації слів.
5. Після накопичення даних у Search Console оцінити покази, CTR і фактичні запити; переписати слабкі заголовки та описи. Перевірити мобільні Core Web Vitals на реальному hosting.

Google Ads, Shopping, Merchant Center, Meta та TikTok мають власні правила щодо товарів і оголошень. Зв’язок із рекламними кабінетами та приймання реклами в цій роботі не перевірялися.
